# Promotion IA - Formation d'Acculturation

## 📋 Vue d'ensemble

Site web de promotion pour la formation **"Acculturation à l'Intelligence Artificielle"** proposée par **Artemys Belgium**.

Formation intensive de **1/2 journée** (4 heures) destinée aux professionnels souhaitant comprendre et intégrer l'IA dans leurs pratiques quotidiennes.

---

## 🎯 Objectifs

- Démystifier l'IA pour un public non-technique
- Découvrir les applications concrètes de l'IA
- Maîtriser les enjeux éthiques et réglementaires
- Apprendre à utiliser les outils IA en toute sécurité
- Gagner en productivité immédiatement
